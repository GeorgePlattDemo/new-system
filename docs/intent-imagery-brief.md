# Imagery brief for Claude

Use the existing application at https://system-candidate-production.up.railway.app/live/system-build-current.html and the assets in this repository. Improve the cohesion of its five projects through imagery. Do not rebuild the application or create another implementation.

The common process is **Idea → Intent → The Bench → The Store answers → Your call → We cut it → Pick up & build**. Idea may be a scan, photo, sketch, plan or remembered object. Intent carries a smaller version of that same reference beside **Grab your wood** and **Bring your tools**. The Bench is the working surface for those tools. Start Your Own may combine its initial choices in the first frame.

Use these existing references first:

| Project | Existing reference | Treatment |
|---|---|---|
| Start Your Own | Its existing cross-brace board representation | Keep the working diagram and its readable geometry. |
| Alcove / critical fit | The room SVG in `public/live/system-build-base-8d8a9dd.html` | Keep the fireplace, alcove, observed wall bow and floor slope. Show the same room in Idea and the smaller Intent reference. |
| Window Seat / space utilization | `public/live/window-seat-hero-0.9.webp` and `window-seat-elevation-0.9.webp` | Keep the existing room photo and the separate controlling sketch. |
| Outdoor Build | Both photos in `public/live/assets/outdoor/` | Keep each published plan's own table. Carry the selected photo and source into Intent. |
| Playhouse arched window | The existing sheet/window SVG in `public/live/system-build-current.html` | Keep the sheet, opening, retained pieces and tabs. |

First identify an actual missing image. Do not replace an existing usable reference just to generate something new. For a missing reference, create a wide landscape composition with generous crop room, warm natural wood, neutral background and restrained light. Match the existing project's object and surroundings. Supply a full Idea image and a smaller Intent crop from the same image; do not depict different projects in those two views.

Keep numbers, dimension arrows, controls, tool locations, prices and manufacturing claims out of generated raster images. The application's existing diagrams and text own those facts. An inspirational rendering does not establish fit, structural adequacy or machine capability. Do not alter a published plan or show operations missing from its definition.

Return the proposed asset, its crop and the exact existing image slot it would fill. Keep code changes limited to approved image references and crop styling. System defines the job; Store alone evaluates it and supplies prices. Physical production remains blocked.
