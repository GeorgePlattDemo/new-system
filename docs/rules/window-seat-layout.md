# window-seat-layout/1

This is an engine extension. A recipe cannot grow this geometry by data alone.

- Elevation thickness T is 0.75 in. That is a design thickness, not a Store price.
- Runs across the depth: the fewest n from 1 to 6 such that depth/n is at most 11.25 in.
- Run width is depth/n, rounded to 0.001 in.
- Dressed widths: 2→1.5, 3→2.5, 4→3.5, 6→5.5, 8→7.25, 10→9.25, 12→11.25. An exact match is that nominal. Otherwise the next wider board is ripped to the run width.
- The top tower shelf lines up with the center upper shelf. Shelves under it divide that space evenly.
- Side spots, if asked, are only centered, 1.5 in inset, or 2 in inset.
